# Internet Mysteries

An open, evidence-first archive for investigating strange corners of the internet.

## Product principles

- Separate verified facts, primary artifacts, secondary reporting, community leads and speculation.
- Label uncertainty honestly. A mystery is not proof of a conspiracy.
- Never publish private personal information or encourage doxxing.
- Keep sources attached to the claims they support.
- Update a case when better evidence changes its status.

## Stack

- Next.js 15 + React 19 + TypeScript
- Tailwind CSS 4 (with a custom editorial design system)
- Local TypeScript data for the initial case archive
- GitHub Issues for early community contributions

## Getting started

Requirements: Node.js 20.9 or newer.

\`\`\`bash
npm install
npm run dev
\`\`\`

Open http://localhost:3000.

## Current MVP

- Searchable case archive
- Status filters
- Individual investigation pages
- Evidence locker and source links
- Competing theories
- Timelines and open questions
- GitHub contribution entry points

The initial case notes are starter research records, not definitive investigations. Verify primary sources before treating any claim as established.

## Roadmap

1. Add structured contribution templates and review workflow.
2. Add provenance fields, source snapshots and evidence change history.
3. Add community verification with moderation.
4. Add interactive investigation boards and linked case timelines.
5. Add database-backed accounts only when community participation requires them.

## Contributing

Open an issue with:
- Case title and central question
- Exact source URL and archive URL where possible
- Capture date or publication date
- What the source demonstrates
- What it does not demonstrate
- Any privacy or safety concerns

Do not submit personal addresses, private contact information, credentials, or identifying information about private individuals.
